> **EcoTrack** — современное высококонтрастное веб-приложение для точного расчета, глубокой визуализации и последовательного сокращения личного углеродного следа ($CO_2e$). Приложение сочетает научно выверенные коэффициенты эмиссии, интерактивную аналитику с плавной анимацией, соревновательный глобальный рейтинг и ежедневный трекер эко-привычек с геймификацией и конфетти.

## ✨ Ключевые возможности

- 🧮 **Мгновенный расчет $CO_2$ в реальном времени**: Ввод параметров без перезагрузок с немедленной переоценкой выбросов по 4 основным секторам жизнедеятельности.
- 📊 **Плавная интерактивная графика**: Диаграмма-пончик (Donut chart), детальная разбивка категорий, международные бенчмарки и физические эквиваленты с анимацией появления на базе `framer-motion`.
- 🏆 **Глобальный рейтинг (Global Leaderboard)**: Сравнение личного следа со статистической моделью сообщества (14 850 участников), определение ранга, процента опережения и переход по экологическим лигам (от Бронзовой до Изумрудной).
- 💡 **Умные рекомендации**: Персонализированный каталог эко-советов с расчетом предотвращенного $CO_2$ (кг/год) и финансовой экономии (руб/год) с возможностью добавления в трекер в один клик.
- 🎉 **Геймифицированный трекер эко-привычек**: Интерактивный 7-дневный календарь, фиксация серии дней (стриков) и многостадийный праздничный салют конфетти (`canvas-confetti`) при 100% выполнении плана на день.
- ⚡ **Готовые жизненные профили**: Быстрая загрузка предустановленных сценариев («Эко-активист», «Городской житель», «Среднестатистический», «Частый путешественник»).
- 🌙 **Высококонтрастная темная тема**: Продуманный интерфейс в глубоких тонах (`#0a0c10`, `#121620`) с акцентной изумрудно-янтарной индикацией для снижения усталости глаз.
- 💾 **Автономность и персистентность**: Полное сохранение введенных данных и состояния привычек в `localStorage` браузера.

## 🖥 Архитектура и разделы приложения

### 1. Интерактивный калькулятор эмиссии
Охватывает 4 фундаментальные категории с гибкой настройкой параметров:
- **Транспорт**: километраж на личном автомобиле в неделю, тип топлива (бензин, дизель, гибрид, электромобиль), часы поездок на общественном транспорте, количество коротких (< 3 ч) и дальнемагистральных (> 3 ч) перелетов в год.
- **Жилье и энергия**: тип жилья (квартира / частный дом), площадь, количество жильцов (распределение общих затрат), ежемесячный расход электроэнергии (кВт·ч), тип отопления (газ, электричество, центральное, биотопливо) и процент экологически чистой / возобновляемой энергии.
- **Питание и рацион**: структура питания (мясной рацион, умеренное потребление, пескетарианство, вегетарианство, веганство), доля локальных и сезонных продуктов, уровень пищевых отходов.
- **Потребление и быт**: частота покупок одежды и товаров длительного пользования, глубина раздельного сбора и переработки отходов, частота обновления персональной электроники.

### 2. Аналитический дашборд и графики (Framer Motion)
- **Категорийная диаграмма (Donut Chart)**: Визуализация пропорций углеродного следа с центровым бейджем ранга и интерактивной легендой.
- **Прогресс-бары с тоннажем**: Наглядное отображение вклада каждого сектора в общую сумму.
- **Сравнение с глобальными ориентирами**:
  - Цель Парижского климатического соглашения: **2.0 т** $CO_2e$/год
  - Среднемировой показатель: **4.7 т** $CO_2e$/год
  - Средний показатель по РФ: **11.2 т** $CO_2e$/год
  - Средний показатель по ЕС: **7.5 т** $CO_2e$/год
  - Средний показатель по США: **14.5 т** $CO_2e$/год
- **Эквивалентные метрики**:
  - Количество взрослых деревьев, требуемых для поглощения годовых выбросов пользователя.
  - Эквивалентный пробег на стандартном бензиновом автомобиле (км).
  - Эквивалент в трансконтинентальных перелетах.

### 3. Глобальный рейтинг и экологические лиги
- **Наглядная шкала сравнения**: Интерактивная шкала с градиентным треком и бегунками пользователя и среднего значения сообщества.
- **Система экологических лиг**:
  - 🟢 **Изумрудная лига (Топ 5%)** — углеродный след $\le 1.8$ т/год.
  - 💠 **Платиновая лига** — $1.81$ – $2.6$ т/год.
  - 🟡 **Золотая лига (Осознанные)** — $2.61$ – $3.8$ т/год.
  - ⚪ **Серебряная лига** — $3.81$ – $5.2$ т/год.
  - 🟠 **Бронзовая лига** — $> 5.2$ т/год.
- **Таблица участников**: Динамическая фильтрация («Все», «Топ-10», «Рядом со мной»), отображение стриков, городов и персонального места в рейтинге.

### 4. База эко-советов с расчетом окупаемости
- Каталог практических шагов по снижению эко-следа, разбитый по направлениям и уровням сложности (Легко, Средне, Продвинутый).
- Для каждого совета вычислены:
  - Сокращение выбросов $CO_2$ в килограммах в год.
  - Финансовая экономия в рублях в год.
  - Срок окупаемости инвестиций (если применимо).
- Кнопка **«Взять в привычки»** мгновенно трансформирует совет в регулярную задачу трекера.

### 5. Трекер привычек с праздничным конфетти
- Календарная шкала на 7 дней для быстрой навигации и отметки выполненных действий.
- Учет регулярности (стрик дней) и суммарного объема предотвращенного $CO_2$.
- **Салют конфетти**: при завершении всех запланированных привычек за день активируется многостадийный запуск салюта из конфетти (`canvas-confetti`), а также отображается мотивирующий баннер со статусом «100% выполнения».
- Возможность добавлять собственные персональные привычки с произвольным экологическим весом.

## 🔬 Методология и коэффициенты расчетов

Расчеты базируются на открытых коэффициентах **IPCC (МГЭИК)**, стандартах отчетности **DEFRA (Великобритания)** и аналитических данных **Our World in Data**:

| Категория | Параметр | Коэффициент эмиссии |
|---|---|---|
| **Автомобиль** | Бензин | `0.192 кг CO₂e / км` |
| | Дизель | `0.171 кг CO₂e / км` |
| | Гибрид | `0.108 кг CO₂e / км` |
| | Электромобиль (с учетом энергобаланса сети) | `0.042 кг CO₂e / км` |
| **Общественный транспорт** | Автобус / Метро / Трамвай | `0.85 кг CO₂e / час` |
| **Авиация** | Короткий рейс (< 3 ч, с учетом RFI) | `230 кг CO₂e / перелет` |
| | Дальний рейс (> 3 ч, с учетом RFI) | `1150 кг CO₂e / перелет` |
| **Электроэнергия** | Средняя энергосеть | `0.385 кг CO₂ / кВт·ч` |
| **Питание (база)** | Мясной рацион (частое потребление) | `3200 кг CO₂e / год` |
| | Умеренное потребление мяса | `2150 кг CO₂e / год` |
| | Пескетарианство | `1620 кг CO₂e / год` |
| | Вегетарианство | `1350 кг CO₂e / год` |
| | Веганство | `920 кг CO₂e / год` |
| **Поглощение $CO_2$** | Взрослое дерево | `~22 кг CO₂ / год` |

## 🚀 Установка и локальный запуск

### Требования
- **Node.js** версии 18.0 или выше
- **npm** (или **pnpm** / **yarn**)

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/ecotrack.git
cd ecotrack
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск сервера разработки
```bash
npm run dev
```
После запуска откройте в браузере адрес [http://localhost:3000](http://localhost:3000).

### 4. Проверка типов (Линтинг)
```bash
npm run lint
```

## 📦 Сборка и развертывание

Для создания оптимизированной производственной сборки выполните:

```bash
npm run build
```

Скомпилированные статические файлы будут сохранены в директории `dist/`. Их можно развернуть на любом хостинге статических сайтов (Vercel, Netlify, Cloudflare Pages, GitHub Pages, Firebase Hosting).

Для локального предпросмотра собранного проекта:
```bash
npm run preview
```
